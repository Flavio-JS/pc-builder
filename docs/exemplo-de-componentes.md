# Exemplo de Componentes

Configuração de referência de um PC gamer de alto desempenho, detalhada peça por peça. Cada componente traz suas especificações técnicas e o que realmente deve ser observado ao escolher e combinar as peças.

---

### 1. Processador (CPU)

**Componente:** AMD Ryzen 7 9700X

| Especificação | Valor |
| --- | --- |
| Modelo | AMD Ryzen 7 9700X |
| Soquete | AM5 |
| Frequência (Clock) | 3.8 GHz (Base) até 5.5 GHz (Boost) |
| Cores/Threads | 8 Cores / 16 Threads |
| TDP (Consumo) | 65W (Base) / ~140W (PPT/Turbo) |
| Suporte de Memória | DDR5 até 5600 MT/s nativo |

* **🔍 O que olhar aqui:** O **soquete (AM5)** para escolher a placa-mãe certa, o **TDP/Consumo** para dimensionar o cooler e a fonte, e o **suporte de memória (DDR5)** para comprar a RAM correta.

---

### 2. Placa-Mãe (Motherboard)

**Componente:** ASUS TUF Gaming B650-Plus Wi-Fi

| Especificação | Valor |
| --- | --- |
| Modelo | ASUS TUF Gaming B650-Plus Wi-Fi |
| Soquete / Chipset | AMD AM5 / Chipset AMD B650 |
| Formato (Tamanho) | ATX |
| VRM (Fases) | 12+2 Fases de Alimentação (60A) com dissipadores massivos |
| Slots de Memória | 4x slots DDR5 (suporte até 192GB e overclock para 7600+ MHz) |
| Armazenamento | 2x Slots M.2 NVMe PCIe 5.0/4.0 x4 |
| Slots de Expansão | 1x PCIe 4.0 x16 (para a placa de vídeo) |

* **🔍 O que olhar aqui:** O **soquete (AM5)** que bate com o processador, o **chipset (B650)** que libera o desempenho do Ryzen 7, as **fases do VRM (12+2)** que garantem energia estável e o **formato (ATX)** para caber no gabinete.

---

### 3. Memória RAM

**Componente:** Corsair Vengeance RGB 32GB (2x16GB)

| Especificação | Valor |
| --- | --- |
| Modelo | Corsair Vengeance RGB 32GB (2x16GB) |
| Tecnologia | DDR5 |
| Velocidade/Frequência | 6000 MHz |
| Latência | CL30 |
| Perfil de Overclock | Suporte a AMD EXPO / Intel XMP 3.0 |

* **🔍 O que olhar aqui:** A **tecnologia DDR5** (placa-mãe e CPU precisam aceitar), a **frequência (6000 MHz)** e a **latência (CL30)**.
* **💡 Dica:** Memórias com frequências altas e latências (CL) baixas são as mais rápidas. Ter 2 pentes (2x16GB) ativa o **Dual Channel**, dobrando a velocidade de comunicação.

---

### 4. Placa de Vídeo (GPU)

**Componente:** NVIDIA GeForce RTX 4070 Super 12GB

| Especificação | Valor |
| --- | --- |
| Modelo | NVIDIA GeForce RTX 4070 Super 12GB |
| Interface | PCIe 4.0 x16 |
| Memória VRAM | 12GB GDDR6X |
| Consumo (TDP) | 220W |
| Conector de Energia | 1x 16-pinos (12VHPWR) ou adaptador de 2x 8-pinos |
| Recomendação de Fonte | Mínimo de 650W |

* **🔍 O que olhar aqui:** A **interface (PCIe 4.0 x16)** que encaixa no slot da placa-mãe, a quantidade de **VRAM (12GB)** para aguentar jogos modernos e inteligência artificial, e o **consumo (220W)** junto com os **conectores de energia** para saber se a sua fonte vai dar conta e tem os cabos certos.

---

### 5. Armazenamento (SSD)

**Componente:** Kingston KC3000 2TB

| Especificação | Valor |
| --- | --- |
| Modelo | Kingston KC3000 2TB |
| Formato / Interface | M.2 2280 / NVMe PCIe 4.0 x4 |
| Velocidade de Leitura | Até 7.000 MB/s |
| Velocidade de Gravação | Até 7.000 MB/s |
| Durabilidade (TBW) | 1600 TBW |

* **🔍 O que olhar aqui:** O formato **M.2 NVMe** (muito mais rápido que SSDs SATA antigos ou HDs), a interface **PCIe 4.0 x4** (sua placa-mãe precisa ter um slot M.2 compatível para rodar na velocidade máxima) e as **velocidades de leitura/gravação** para garantir carregamentos instantâneos.

---

### 6. Fonte de Alimentação (PSU)

**Componente:** MSI MAG A750GL

| Especificação | Valor |
| --- | --- |
| Modelo | MSI MAG A750GL |
| Potência Total | 750 Watts |
| Certificação de Eficiência | 80 Plus Gold |
| Cabeamento | Totalmente Modular |
| Padrão de Construção | ATX 3.0 / PCIe 5.0 Nativo (inclui o cabo de 16 pinos 12VHPWR) |

* **🔍 O que olhar aqui:** A **potência (750W)** deve cobrir a soma do consumo da GPU (220W) + CPU (140W) com uma margem de segurança de ~40%. A **certificação (80 Plus Gold)** garante que ela não desperdiça energia e o padrão **ATX 3.0** garante o cabo moderno direto para a placa de vídeo, sem precisar de adaptadores que possam derreter.
